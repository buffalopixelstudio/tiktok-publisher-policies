## 2. Information used

When a user connects TikTok and requests an upload, the tool may process:

- TikTok account identifiers and basic profile information returned through the approved authorization, such as an account ID, username, display name, and avatar.
- OAuth access credentials needed to make API requests on the user's behalf.
