# Buffalo Pixel Publisher policies

This repository contains working drafts for the Terms of Service and Privacy Policy associated with the TikTok Content Posting integration.

## Draft files

- `terms-of-service-draft.md`
- `privacy-policy-draft.md`

These are not publication-ready. Replace every bracketed field, verify the statements against the shipped software, and obtain appropriate review before publishing or submitting them to TikTok. TikTok requires an externally accessible official website with active links to both documents; a repository by itself may not meet that requirement.
